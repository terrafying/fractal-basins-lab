# Concept — ingression (Whitehead via Levin)

Whitehead (Process and Reality): "ingression" is how an eternal object (a
Platonic pattern) enters a particular actual occasion. Levin applies it to
minds: patterns of anatomy/behavior/cognition pre-exist in a Platonic space;
bodies are interfaces that let them ingress; we don't generate minds, we
facilitate ingression through the interfaces we build.

## In our program
The attractor atlas reading: weights = space of stabilities; prompt = boundary
condition; inference = ingression of a basin. GLM-5.3's objection (the
strong version): basin selection alone is trivially true of any deterministic
map — the content requires basins to be representational AND functionally
reachable. Empirical hooks: native-init answers land in the atlas modal basin
(reachability); the open test is whether natural-prompt error modes coincide
with atlas error basins.
